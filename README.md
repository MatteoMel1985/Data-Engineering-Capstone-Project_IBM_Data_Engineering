<h1 align="center">IBM Data Engineering Capstone Project</h1>  

This repository contains my guide and solutions for the six modules of the IBM Data Engineering Capstone Project on Coursera.
Its purpose is to provide a clear, structured, and practical reference for students completing the final capstone exam, with explanations, commands, queries, and task-by-task guidance.

<h1 align="center"><i>Modules Overview</i></h1>

* [**Module 1 – OLTP Database with MySQL**](https://github.com/MatteoMel1985/Data-Engineering-Capstone-Project_IBM_Data_Engineering/tree/main/Module%201):

This module focuses on designing and implementing an OLTP database for an e-commerce scenario. It covers database creation, table design, data loading, indexing, and basic administrative automation using a Bash export script.  

* [**Module 2 – NoSQL Database with MongoDB**](https://github.com/MatteoMel1985/Data-Engineering-Capstone-Project_IBM_Data_Engineering/tree/main/Module%202):

This module introduces MongoDB as a NoSQL solution for storing e-commerce catalogue data. It includes importing JSON data, querying collections, creating indexes, performing aggregations, and exporting selected fields to CSV.  

* [**Module 3 – Data Warehousing and Reporting with PostgreSQL**](https://github.com/MatteoMel1985/Data-Engineering-Capstone-Project_IBM_Data_Engineering/tree/main/Module%203):

This module covers the design and implementation of a star schema data warehouse using pgAdmin and PostgreSQL. It also includes loading dimension and fact tables, then running analytical SQL queries using grouping sets, rollups, cubes, and materialised query tables.  

* [**Module 4 – Dashboard Creation with Google Looker Studio**](https://github.com/MatteoMel1985/Data-Engineering-Capstone-Project_IBM_Data_Engineering/tree/main/Module%204):

This module focuses on building a business reporting dashboard from e-commerce data. It includes importing CSV data, creating a data source, and visualising key metrics through line charts, pie charts, and bar charts.  

* [**Module 5 – Data Pipelines with Apache Airflow**](https://github.com/MatteoMel1985/Data-Engineering-Capstone-Project_IBM_Data_Engineering/tree/main/Module%205):

This module demonstrates how to create and run an Apache Airflow DAG for processing web server logs. The pipeline extracts IP addresses, transforms the data by filtering specific records, and loads the final output into a compressed archive.

* [**Module 6 – Big Data Analytics with PySpark**](https://github.com/MatteoMel1985/Data-Engineering-Capstone-Project_IBM_Data_Engineering/tree/main/Module%206):

This module applies PySpark to analyse e-commerce search-term data. It includes loading CSV data into a Spark DataFrame, running analytical queries, identifying frequent search terms, and using a pre-trained model to generate a sales forecast.
